# New Features in React 19

React 19 introduces several exciting features and improvements aimed at enhancing developer experience and application performance. This document outlines the key additions.

## React Compiler

Explain the new React Compiler (formerly Forget) and its impact on automatic memoization and performance.

## Actions

Describe the new Actions feature for handling form submissions and asynchronous operations, including `useTransition`, `useActionState`, and `useFormStatus`.

## Server Components (Stable)

Discuss the stabilization of Server Components and their role in building modern web applications with React.

## Asset Loading APIs

Detail the new APIs for asset loading (e.g., stylesheets, fonts, scripts) and how they integrate with Suspense. Mention `<link>` and `<script>` support.

## Web Components Support

Explain the improved support for integrating Web Components within React applications.

## `use` Hook

Describe the new `use` hook for reading resources like Promises and context in render.

## `<Context>` as a Provider

Explain the ability to use `<Context>` directly as a provider instead of `<Context.Provider>`.

## `ref` as a Prop

Detail the change allowing `ref` to be passed as a regular prop to function components.

## Custom Element Support Improvements

Discuss enhancements for working with Custom Elements, including better property and event handling.

## Error Reporting Improvements

Mention improvements in how React reports errors, making debugging easier.

## Deprecations and Breaking Changes

List any significant deprecations or breaking changes introduced in React 19.
